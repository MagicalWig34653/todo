## Entwurf (für ADR 0037)

1. Neue Tabellen, nichts an Bestandsspalten: `project_groups` (je Person, Name eindeutig ohne Groß/Klein), `project_group_members`, `project_selections` (Regel je Grant bzw. Mandat, Id = deren Id: `mode` `selected|all_except`, `group_ids`, `excluded_project_ids`, `excluded_group_ids`), `agent_created_projects`. Ohne Regelzeile gilt die bisherige Liste: Altbestand unverändert.
2. Eine Auflösung (`ProjectSelectionResolver.resolve`): (ausdrücklich + Gruppen + bei `all_except` eigene Projekte) − ausgeschlossene Projekte/Gruppen, geschnitten mit aktuellen Leserechten. „Eigen“ = Besitz als Person (Teamprojekte nicht), ohne per MCP `create_project` angelegte Projekte (sonst vergrößert ein Agent fremde Auswahlen); die nimmt die Person per Gruppe oder Auswahl auf, die Vorschau nennt sie.
3. Grant/Mandat behalten `projects` als ausdrückliche Liste (`explicitProjects`); alle Lesestellen von `grant.projects` und `mandate.projects` (Liste unten) bekommen die aufgelöste Menge, unter Sperre aufgelöst in `lockedBrainAuthority`, `MandatedConnectionService`, `OAuthTakeover`, `ReviewBatch`, `get_connection`, `MCPController.handle` (einmal je Anfrage).
4. Schreiben nur per Sitzung: `GET/POST /v1/project-groups`, `PATCH/DELETE /v1/project-groups/{id}` (`?dryRun=true` liefert Vorher/Nachher je Verbindung/Vollmacht), `GET/PUT /v1/projects/{id}/groups`, `POST /v1/project-selection/preview`; `selection` optional in `PUT /oauth/grants/{id}/projects`, `PUT /v1/settings/brain-mandate`, `POST /oauth/consent`. Ohne `selection` ersetzt die Liste eine Regel (Altclients). MCP nur lesend: `list_project_groups` (nur Gruppen mit erreichbaren Projekten, nur diese), `get_connection.selection`/`brainMandate.mode`.
5. Sperren: Freigabegraph, dann Mandate, dann Grants der Person (je `ORDER BY id FOR UPDATE`), dann Gruppen; Entscheidungen sperren Mandat, Grant, dann lesen sie Gruppen mit `FOR UPDATE`. Gruppenänderung mit Wirkung auf eine aktive Vollmacht schreibt `mandate.group_added|group_removed` in `brain_connection_audits`. Gruppe löschen: als Ausschluss bleiben ihre Projekte einzeln ausgeschlossen (Löschen erweitert nie).
